qClip Desktop — Install & First Clip

No Docker required · Windows & macOS (Apple Silicon) · Beta v1.0.0-beta.5

Creator path — installers only

You do not need Docker. Install the desktop app for your OS, activate your license, run one short job.

Get the installer from your invite kit (installers/), Drive link, or Lemon Squeezy — not from a public GitHub download URL (private repo → 404).

Part 1 — Windows

What you need

  • Windows 10 or 11 (64-bit)
  • ~16 GB RAM (32 GB better)
  • NVIDIA GPU recommended (CPU works, slower)
  • License key from invite email (SCPRO-…)
  • Installer: qClip-Setup-win-x64.exe

Steps

  1. Get the installer — invite kit → installers\qClip-Setup-win-x64.exe (or Drive / Lemon Squeezy link).
  2. Run the installer — double-click in Explorer.
  3. SmartScreen (“Windows protected your PC”): More info → Run anyway. Expected for unsigned beta.
  4. Finish setup — defaults → Install → Finish.
  5. Launch qClip — Start menu → qClip. Wait for splash → UI (first launch may download models).
  6. Confirm ready — Settings → Get started → Ready. If Needs attention, use Help → Troubleshooting first.
  7. Activate license — Settings → License → paste key → Activate.
  8. First clip — New job → short public YouTube/Twitch URL → wait for done → play a clip.
  9. Confirm logs — Win+R → paste %LOCALAPPDATA%\qClip\logs\ → sidecar.log and electron.log.
Optional (repo): .\scripts\fetch_desktop_artifacts.ps1 -Tag v1.0.0-beta.5 then .\scripts\run_windows_solo_smoke.ps1

Zip logs for support

Compress-Archive -Path "$env:LOCALAPPDATA\qClip\logs" `

Pass checklist

  • Installed without Docker
  • SmartScreen handled (More info → Run anyway)
  • Splash → UI
  • License activated
  • Short job completed
  • Clip plays
  • Logs folder present

Part 2 — macOS (Apple Silicon)

What you need

  • Mac with Apple Silicon (M1/M2/M3/…)
  • macOS 12+
  • ~16 GB RAM (32 GB better)
  • License key (SCPRO-…)
  • Installer: qClip-mac-arm64.dmg from kit, or build it (below)

Steps

  1. Get the DMG — invite kit → installers/qClip-mac-arm64.dmg.
  2. Open the DMG in Finder.
  3. Install — drag qClip to Applications.
  4. Gatekeeper — Applications → right-click qClip → Open → Open (unsigned beta).
  5. Launch — splash → UI (first run may download models).
  6. Confirm ready — Settings → Get started → Ready.
  7. Activate license — Settings → License → Activate.
  8. First clip — short URL → done → play clip.
  9. Confirm logs — ~/Library/Application Support/qClip/logs/

Zip logs for support

zip -r ~/Desktop/qclip-smoke-mac-logs.zip "$HOME/Library/Application Support/qClip/logs"

Pass checklist

  • Installed without Docker
  • Gatekeeper handled (right-click → Open)
  • Splash → UI
  • License activated
  • Short job completed
  • Clip plays
  • Logs folder present

Build the DMG (if missing from kit)

On Apple Silicon Mac: Node 20+, Python 3.11+, Xcode CLT, ~15 GB free.

cd /path/to/streamclip
./scripts/build_macos_solo.sh
# → apps/desktop/release/qClip-mac-arm64.dmg
./scripts/run_macos_solo_smoke.sh
# Copy DMG into invite kit installers/

What not to do

  • Do not install Docker Desktop for the creator beta
  • Do not use anonymous GitHub release URLs (404)
  • Do not start with a long VOD — use a short clip first

Help

  • In-app: Help → Troubleshooting or Report a bug
  • Reply to your invite email with job ID + log zip if something fails
