# qClip Beta — Quickstart

**~15 minutes from installer to first clip.** No Docker, no GitHub account, no command line.

!!! tip "Want the full walkthrough?"
    See the **[Desktop install guide](DESKTOP_SOLO_USER_GUIDE.md)** — Windows and Mac, step by step with checklists.

---

## The short version

1. Install **`qClip-Setup-win-x64.exe`** (Windows) or **`qClip-mac-arm64.dmg`** (Mac) from your invite kit
2. Open **qClip** → **Settings → License** → paste **`SCPRO-…`**
3. **New job** → paste a **short public video URL** → wait for **done** → play a clip

---

## What you need

| Item | Details |
|------|---------|
| **Installer** | From invite kit `installers/` — [download help](BETA_DOWNLOAD.md) |
| **License key** | Invite email — format `SCPRO-XXXX-XXXX-XXXX-XXXX` |
| **RAM** | 16 GB minimum · 32 GB recommended |
| **First test video** | Short public URL (10–20 min ideal) — not a 3-hour VOD |

---

## Install in three moves

=== "Windows"

    1. Run **`installers\qClip-Setup-win-x64.exe`**
    2. SmartScreen? **More info → Run anyway**
    3. **Start menu → qClip**

=== "macOS"

    1. Open **`installers/qClip-mac-arm64.dmg`** → drag to **Applications**
    2. Blocked? **Right-click qClip → Open → Open**
    3. Launch from Applications

Full detail: [Desktop install guide](DESKTOP_SOLO_USER_GUIDE.md)

---

## Unlock & verify

1. **Settings → Get started** → must show **Ready**
2. **Settings → License** → paste key → **Activate**

---

## Your first job

1. **New job** on the home screen  
2. Paste a public URL (YouTube, Twitch, Kick, or `.mp4`)  
3. Submit → watch progress  
4. Status **done** → open a clip → play it  

Deep dive: [Your first clip tutorial](tutorials/TUTORIAL_FIRST_JOB.md)

---

## Speed guide

| Machine | ~1 hour of source video |
|---------|-------------------------|
| Windows + NVIDIA GPU | ~20–25 min |
| Windows / Mac CPU only | ~60–90+ min |

Start with a **short** video while learning the app.
