# Create your first clip (operator notes)

> **Creators:** use the public page — [Download & how to use](index.md) (henna home). This file is **not published**.

You already installed qClip and activated your license. This page is only about **running a job**.

!!! tip "Don't have the app yet?"
    **Call to action:** [Install qClip](BETA_DOWNLOAD.md) — then come back here.

---

## 1. Confirm you're ready

1. Open qClip (Start menu on Windows, **Applications** on Mac, or [http://localhost:3000](http://localhost:3000) on Docker).
2. **Settings → Get started** should say **Ready**.
3. If it says **Needs attention**, fix those items first — or see [Troubleshooting](tutorials/TUTORIAL_TROUBLESHOOTING.md).

---

## 2. Start a job

1. Click **New job**.
2. Paste a **public** video URL or upload a file:
   - YouTube, Twitch VOD, Kick, or a direct `.mp4`
3. Optional: set a title → **Submit**.
4. Watch stages: download → transcribe → detect → render.
5. When status is **done**, open the clip list.

### How long? (CPU desktop)

| Source | Typical time |
|--------|----------------|
| ~15 minutes | ~10–20 minutes |
| ~1 hour | ~60–90+ minutes |

GPU Docker hosts are much faster. For beta feedback, prefer a short public clip.

---

## 3. Approve and publish (optional)

1. Open a finished clip → preview → **Approve**.
2. **YouTube Shorts:** **Settings → Distribution → Connect YouTube Shorts** → Google sign-in → **Publish** on an approved clip.
3. **TikTok:** inbox / drafts only during beta — finish in the TikTok app.

!!! note "Scheduled posts"
    On the Windows desktop app, scheduled publishes only fire while qClip is running.
